# Ingestion + Core Data Model Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ingest real messages from Caspian (email, Telegram, Slack, Discord) across the 3 Sieve agent identities into Postgres, with sender resolution and dedup, running as an isolated worker process separate from the FastAPI API server.

**Architecture:** A new `apps/server/app/ingest/` package holds a `worker.py` entrypoint (own Docker Compose service, own container command) that builds a `caspian_sdk.CommClient`, registers the 3 identities across their channels, and attaches one `on_message` handler. The handler composes three small, independently-tested functions — dedup/persist (`message_store.py`), sender resolution (`sender_resolution.py`) — against three new SQLAlchemy models (`Message`, `PersonEntity`, `ChannelHandle`) and one Alembic migration. The FastAPI process (`app/main.py`) is untouched by this plan.

**Tech Stack:** FastAPI + SQLAlchemy 2.x + Alembic (existing, uv-managed), `caspian-sdk` (new, PyPI, real SDK — not mocked), pytest with an in-memory SQLite fixture for unit tests, Docker Compose for local dev.

## Global Constraints

- Python dependency management stays on `uv` (`uv add`, `uv run`) — uv already manages an isolated `.venv` per `apps/server`; no manual `python -m venv`/`pip`.
- `caspian-sdk` is the real PyPI package (confirmed to exist, MIT, `Python >= 3.10`), installed via `uv add caspian-sdk` — never mocked as the production implementation. Fake message objects are only used inside unit tests of our own handler logic, never a fake `CommClient`.
- The Caspian listener (`client.listen()`, a blocking loop) runs as its own process/container (`ingest` service), never as a background thread inside the FastAPI server — this keeps `uvicorn --reload` from tearing down the Caspian connection on unrelated file saves and keeps a handler crash from taking the HTTP API down.
- Exactly 3 identities on one `CommClient`, one `on_message` handler, one `listen()` loop (spec's own constraint: never one listener per identity). Channel-to-identity mapping, derived from spec §2.1 + §3: `careers` → email only; `support` → email + Telegram; `internal` → email (forwarding target) + Slack + Discord.
- Only 3 of the spec's 8 tables are created now: `messages`, `person_entities`, `channel_handles`. The other 5 (`org_roles`, `buckets`, `rules`, `routing_decisions`, `overrides`) are out of scope — they land with the sub-projects that consume them.
- Dedup is enforced twice: an app-level lookup before insert, and a DB-level `UNIQUE` constraint on `messages.caspian_message_id` as a safety net.
- Per-message error isolation: one malformed/failing message is logged and dropped, never crashes the worker loop.
- Unit tests use an in-memory SQLite engine with `StaticPool` (so all sessions in a test share the same in-memory DB) — never the real Postgres — via a shared `apps/server/tests/conftest.py` fixture.
- Secrets (`CASPIAN_API_KEY`, `CASPIAN_BASE_URL`, `TELEGRAM_BOT_TOKEN`, `DISCORD_BOT_TOKEN`) are never hardcoded into `docker-compose.yml` (unlike the existing non-secret Postgres dev credentials, which stay hardcoded per the existing pattern). They're injected via Compose's built-in `${VAR}` interpolation from a root `.env` (gitignored, values documented in `.env.example`) — a deliberate, narrow exception to the "no env substitution" convention noted in the README, justified because this value is a real credential.
- Real Caspian credentials are already available (confirmed with the user) — the final task is a live smoke test against the actual gateway, not a mock.

from sqlalchemy import select
from sqlalchemy.orm import Session

from app.models.channel_handle import ChannelHandle
from app.models.person import PersonEntity


def resolve_sender(db: Session, *, channel: str, handle: str) -> PersonEntity:
    existing = db.execute(
        select(ChannelHandle).where(
            ChannelHandle.channel == channel, ChannelHandle.handle == handle
        )
    ).scalar_one_or_none()
    if existing is not None:
        return existing.person_entity

    person = PersonEntity(display_name=None, is_provisional=True)
    db.add(person)
    db.flush()

    channel_handle = ChannelHandle(person_entity_id=person.id, channel=channel, handle=handle)
    db.add(channel_handle)
    db.flush()
    return person
```

from datetime import datetime, timezone
from typing import Any

from sqlalchemy import select
from sqlalchemy.orm import Session

from app.models.message import Message


def is_duplicate(db: Session, caspian_message_id: str) -> bool:
    existing = db.execute(
        select(Message.id).where(Message.caspian_message_id == caspian_message_id)
    ).scalar_one_or_none()
    return existing is not None


def persist_message(
    db: Session,
    *,
    caspian_message_id: str,
    agent_id: str,
    channel: str,
    sender_handle: str,
    thread_id: str | None,
    raw_payload: dict[str, Any],
) -> Message:
    message = Message(
        caspian_message_id=caspian_message_id,
        agent_id=agent_id,
        channel=channel,
        sender_handle=sender_handle,
        thread_id=thread_id,
        raw_payload=raw_payload,
        received_at=datetime.now(timezone.utc),
    )
    db.add(message)
    db.flush()
    return message
```

```python
import logging
from collections.abc import Callable
from typing import Any

from sqlalchemy.orm import Session

from app.ingest.message_store import is_duplicate, persist_message
from app.ingest.sender_resolution import resolve_sender

logger = logging.getLogger(__name__)


def _field(message: Any, *names: str) -> Any:
    for name in names:
        value = getattr(message, name, None)
        if value is not None:
            return value
    return None


def build_on_message_handler(session_factory: Callable[[], Session]) -> Callable[[Any], None]:
    def handle(message: Any) -> None:
        db = session_factory()
        try:
            message_id = _field(message, "id", "message_id")
            if message_id is None:
                logger.error("Dropping message with no id: %r", message)
                return

            if is_duplicate(db, message_id):
                return

            channel = _field(message, "channel")
            agent_id = _field(message, "agent_id", "identity")
            thread_id = _field(message, "thread_id")
            sender = getattr(message, "sender", None) or {}
            sender_handle = sender.get("address") if isinstance(sender, dict) else None
            text = _field(message, "text")

            if not (channel and agent_id and sender_handle):
                logger.error(
                    "Dropping message %s: missing required field(s) "
                    "(channel=%r agent_id=%r sender=%r)",
                    message_id,
                    channel,
                    agent_id,
                    sender_handle,
                )
                return

            resolve_sender(db, channel=channel, handle=sender_handle)
            persist_message(
                db,
                caspian_message_id=message_id,
                agent_id=agent_id,
                channel=channel,
                sender_handle=sender_handle,
                thread_id=thread_id,
                raw_payload={
                    "text": text,
                    "sender": sender,
                    "channel": channel,
                    "agent_id": agent_id,
                    "thread_id": thread_id,
                },
            )
            db.commit()
        except Exception:
            db.rollback()
            logger.exception("Failed to handle message %r", getattr(message, "id", None))
        finally:
            db.close()

    return handle
```

from caspian_sdk import CommClient

from app.core.config import settings

IDENTITY_CHANNELS: dict[str, list[str]] = {
    "careers": ["email"],
    "support": ["email", "telegram"],
    "internal": ["email", "slack", "discord"],
}


def register_identities(client: CommClient) -> None:
    for identity, channels in IDENTITY_CHANNELS.items():
        if "email" in channels:
            client.connect_email(username=identity)
        if "telegram" in channels:
            client.connect_telegram(bot_token=settings.telegram_bot_token, username=identity)
        if "slack" in channels:
            client.install_slack(username=identity, display_name=f"Sieve ({identity})")
        if "discord" in channels:
